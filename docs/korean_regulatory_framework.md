# 한국 법제도와 연결된 최소노출형 사전검토 workflow

본 문서는 본 연구의 운용점(**색인 `full_text` / 반환 `minimal_text`, hybrid α=0.5 — 다국어 dense 성분 포함**)을 한국 전략물자 수출통제 체계와 연결하여, "정보 최소 노출 하에서의 사전 후보검토"를 제도적으로 설명한다.

## 1. 관련 한국 법제 요약

### 1.1 대외무역법
- **목적**: 수출입 및 해외투자의 공정한 거래질서 확립, 무역의 자유와 균형 있는 국제수지 유지
- **전략물자 관련 조항**: 제18조(전략물자등 수출의 제한), 제19조(전략물자등 수출승인 등)
- **핵심**: 전략물자 수출 시 사전 승인·신고·자기판정 등의 절차를 거쳐야 한다.
- **출처**: [법제처 대외무역법](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=241530&lsNm=%EB%8C%80%ED%99%98%EB%AC%B4%EC%97%85%EB%B2%95#0000)

### 1.2 전략물자 수출입고시
- **목적**: 대외무역법 제18조에 따른 전략물자등의 수출입 기준과 절차를 구체적으로 규정
- **핵심**: 
  - 전략물자 수출 시 수출신고를 하여야 하며, 신고서에는 물품명, 규격, 용도, 최종소비자 등을 기재
  - 신고 내용이 사실과 다르거나 누락 시 과태료·취소 등의 제재
- **업무 흐름**: 수출자 → (수출신고) → 산업통상자원부 장관 → (심사) → 승인/거부
- **출처**: [전략물자 수출입고시](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000270104&chrClsCd=010201)

### 1.3 산업기술보호법
- **목적**: 국가핵심기술과 산업기술의 유출 방지, 기술보호 체계 구축
- **핵심**: 해외 기업·기관과 기술협력 시 기술이전 계약서에 기술보호 조항을 포함하는 등 기술유출 방지 조치를 강구하여야 함
- **관련**: 전략물자 수출 신고 시 기술자료가 함께 이전되는 경우, 산업기술보호법상 '해외 유출'로 평가될 수 있음
- **출처**: [산업기술보호법](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=247501&lsNm=%EC%82%B0%EC%97%85%EA%B8%B0%EC%88%A0%EB%B3%B4%ED%98%B8%EB%B2%95#0000)

### 1.4 국가핵심기술 제도
- **목적**: 국가경쟁력·안보에 핵심적인 기술의 해외 유출 방지
- **핵심**: '국가핵심기술'로 지정된 기술은 해외 이전 시 별도 승인 필요
- **운영**: 산업통상자원부·국가안보실·방위사업청 등이 협의하여 지정·관리
- **참고**: 국가핵심기술의 해외 이전은 산업기술보호법과 대외무역법을 동시에 적용받을 수 있음
- **출처**: [국가핵심기술 제도](https://kaits.or.kr/web/content.do?menu_cd=000067)

## 2. 최소노출형 사전검토 workflow 제안

본 연구의 운용점(색인 `full_text` / 반환 `minimal_text`)과 hybrid 검색 성능은, 아래 workflow에서 "사전 단계 보조 도구"로 활용될 수 있다.

```
기업 담당자
   │
   ▼
(Step 1) 제품·기술 설명을 시스템에 입력
   → "리튬이온 배터리 양극재 제조장비를 인도 업체에 수출"
   → 입력 정보는 내부 서버에만 저장, 외부 AI/검색 서비스에 전송하지 않음
   │
   ▼
(Step 2) hybrid(α=0.5, BM25 + 다국어 dense)로 공개 통제목록 후보검색
   → 색인은 full_text, 반환만 minimal_text
   → 반환: 통제번호 + 핵심 설명 1문장
     (위 질의를 실제로 넣었을 때의 top-1:
      "ECCN-1B233 | Lithium isotope separation facilities or plants,
       and systems and equipment therefor")
   → 전체 원문은 반환하지 않음
     (노출량@10 7,886.2 → 1,780.8자, 77.4% 감소, R@10 변화 정확히 0.0000)
   │
   ▼
(Step 3) 후보 목록 확인 → 관련 항목이 있는 경우 YesTrade 자가평가 또는 전문평가로 이동
   → 최종 판정: 공식 절차 (YesTrade / 관세사 / 산업통상자원부)
   │
   ▼
(Step 4) 신고서 작성 시 필요 최소한의 정보만 사용
   → 통제번호, 품목명, 규격, 용도, 최종소비자
   → 기술자료(도면, 특허 등)는 별도 산업기술보호법 검토 필요
```

### Step 2 검색기 규정에 대한 주석

- **BM25 단독은 이 workflow에 쓸 수 없다.** 한국어 질의에서 BM25의 R@10은 위 운용점(색인 `full_text`)에서 **0.0367(4/109)**, 색인을 `minimal_text`로 줄이면 **0.0275(3/109)**다. 어느 쪽이든 109개 중 각각 95개·96개는 코퍼스(100% 영어)와 어휘 교집합이 0이어서 후보를 한 건도 만들지 못한다. 한국 기업 담당자가 한국어로 쓰는 절차에 BM25를 규정하는 것은 실패를 규정하는 것과 같다. 다국어 dense 성분을 넣으면 같은 조건에서 한국어 R@10이 **0.5596(61/109)**으로 올라간다(hybrid α=0.5, 색인 `full_text`, MiniLM, n=151). dense 도입이 Step 1의 "외부 전송 금지"와 충돌하지 않는다는 점이 중요하다. 본 연구가 쓴 인코더(`paraphrase-multilingual-MiniLM-L12-v2`)는 로컬 GPU에서 전량 실행되므로, 외부 AI 서비스 호출 없이 사내 서버에서 그대로 구동할 수 있다.
- **α=0.5를 기본으로 하되, 확정적으로 규정되는 것은 "dense 성분이 반드시 있어야 한다"까지다.** hybrid가 dense 단독보다 나은지는 Holm 보정 후 유의하지 않다(색인 `full_text` 기준 +0.0331, 5승 0패, p_adj=0.3125). dense 단독(α=0.0)도 허용 범위이며, 배제되는 것은 BM25 단독뿐이다.
- **반환 축소는 통제번호를 남긴 채로만 한다.** `minimal_no_code`는 1,691.0자까지 더 줄지만 통제번호를 지운다. 지표는 코퍼스 메타데이터로 채점하므로 떨어지지 않으나, 담당자는 식별자 없는 문장만 받아 후보를 특정할 수 없다. 이 workflow의 산출물은 후보 통제번호이므로 운용점에서 제외한다.
- **top-1이 정답이라는 뜻이 아니다.** 위 예시에서 배터리 양극재 질의에 리튬 *동위원소 분리설비*(핵 관련 항목)가 1위로 올라온다. 어휘·의미가 부분적으로 겹치는 무관 항목이 상위에 오는 것은 정상 동작이며, 그래서 Step 3의 사람 판정이 생략 불가능하다.

## 3. 법제도적 기여와 한계

### 기여
- **정보최소화 원칙**: 현재 한국 수출통제 신고 절차는 대부분 오프라인 또는 전용 시스템 내에서 진행되지만, 외부 검색 서비스 활용이 확대되는 상황에서 "어떤 정보까지 외부에 전송해도 되는가"에 대한 기준점을 제시한다. 단, 두 채널을 혼동하면 안 된다. Step 2의 반환 축소(7,886.2 → 1,780.8자)가 줄이는 것은 **이미 공개된** 통제목록 문언이므로 기업 영업비밀 보호와는 무관하다. 기업 기술정보는 Step 1의 **질의 측**으로 나가며, 그쪽을 줄이는 데는 실제 대가가 따른다(질의 L0→L2에서 hybrid R@10 0.5188 → 0.4211, n=133; `output/disclosure_frontier.md`).
- **사전검색 보조**: hybrid(α=0.5) 검색은 YesTrade 자가평가 전 단계에서 "어떤 통제번호가 관련 있을 수 있는지"를 빠르게 식별하는 1차 필터로 사용할 수 있다. 다만 검증셋 기준 R@10은 0.5497(83/151)이므로 정답이 상위 10건에 들어오지 못하는 질의가 절반 가까이 남는다. 1차 필터이지 판정기가 아니다.
- **법적 책임 분리**: 본 시스템이 후보를 제시하는 수준까지 기능을 제한하면, 최종 판정은 공식 절차에 맡기므로 법적 책임 소재가 명확해진다.

### 한계
- 어휘 매칭만으로는 전문 용어·동의어 커버리지가 제한된다는 초판의 진단은 유효하다. 다만 그 처방이던 "Dense retrieval 결합은 후속 연구"는 더 이상 한계가 아니다. 결합은 이미 수행됐고(n=151, 인코더 3종), 한국어 구간에서 dense가 BM25를 이긴다는 것이 Holm 보정 후에도 유의하다(+0.5046, 57승 2패, p_adj≈0, 색인 `full_text`, MiniLM). 그래서 dense 성분은 후속 과제가 아니라 §2 Step 2의 필수 구성요소로 규정했다.
- 실제 기업 질의로의 일반화는 여전히 미검증이다. 초기 상담형 모사 질의셋 30개(코퍼스 v1 1,797건, 연구자 추정 라벨·30개 중 13개 코드충돌)에서 BM25는 **0/30**이었고 hybrid α=0.5도 3/30에 그쳤다(`output/external_retriever.json` — 재실행하지 않은 stale 산출물이므로 현행 수치가 아니다). 현재(코퍼스 v2 1,783건, 검증셋 n=151)의 hybrid α=0.5 R@10은 0.5497이지만, 이 질의들은 통제항목을 먼저 고르고 그 항목을 묘사해 **역생성**한 것이라 라벨이 구조적으로 확정된다. 실제 상담 현장의 질의 분포와 같다는 보장은 없다. (초판은 이 자리에 "합성 벤치마크와 상담형 모사 질의셋의 결과가 0/30"이라 적었으나, 0/30은 상담형 모사 질의셋만의 값이며 합성 벤치마크에는 해당하지 않는다.)
- 본 workflow는 사전검색 보조일 뿐, 수출 신고 승인을 대체하지 않는다.
- 국가핵심기술 지정 여부는 별도로 확인해야 하며, 본 시스템의 검색 결과로 판단하지 않는다. 본 연구는 국가핵심기술을 자동 판단하지 않는다.
