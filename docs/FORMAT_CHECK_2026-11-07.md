## 2. v1.1에서 바뀐 것 (전부 서식, 본문 글자는 한 자도 바꾸지 않음)

1. 머리말 생성: 홀수쪽 오른쪽 `전략물자 사전검토 단계의 질의 노출 최소화 N`, 짝수쪽 왼쪽 `N 韓國産業保安硏究 - 第16卷 第1號 (2026)`, 머리말 밑줄 포함. 표지에는 안 나옴.
2. 꼬리말 `- N -` 제거 (머리말 쪽번호로 대체). 쪽번호는 요약 쪽부터 1.
3. `ABSTRACT` 가운데 정렬 (공백 채움 제거).
4. 영문 제목 두 문단 → 한 문단 가운데 정렬 ("Stage" 고아행 해소).
5. 영문 저자 각주 3줄: 고딕 10pt 양쪽정렬 → 신명조 9pt 왼쪽정렬 (국문 쪽과 동일).
6. 표·그림 캡션 15개: 고딕 10pt (집필요령 5-2(1)).

## 3. 사람이 한글에서 확인·결정할 것

- **한글로 열어 30쪽인지, 그림 1~8이 제자리에 있는지 확인.** rhwp 렌더러는 글자처럼 취급되지 않은 그림(그림 2·3 등)을 본문 위에 겹쳐 그리는데, **이는 원본 v1.0 렌더링에서도 똑같이 나타나는 렌더러 한계**다(한글에서 만든 8월 PDF에서는 정상). v1.1 때문에 생긴 것이 아니다.
- **머리말의 `第16卷 第1號 (2026)`** 는 학회 샘플 문구 그대로다. 수상작은 「한국산업안보연구」 특집호 게재 대상이므로 권·호는 편집부가 정한다. 그대로 두어도 되고, 신경 쓰이면 한글에서 머리말만 고치면 된다.
- **표 세로선.** 집필요령 5-2(4)는 "세로선 없음"인데 학회 샘플의 표 1에는 세로선이 있다. 규정을 따르려면 표 8개의 세로 괘선을 한글에서 지워야 한다(rhwp로는 안전하게 못 한다). 샘플이 그러니 감점 가능성은 낮다고 본다.
- **국문 요약 529자** — 집필요령 600자 안팎 / 투고규정 500자 내외. 둘 사이에 있어 그대로 뒀다.
- **표 4 아래 "주 : 1)" 두 줄이 표에 바짝 붙어 보이는 것**은 렌더러 차이. 한글에서 한 줄 띄어 보이는지 확인.
- **공고 요건:** 유사도 검사 결과 제출(10% 이상이면 사유서), 발표자료 PPT+PDF, 주저자 참석. 보완 논문은 메일로 제출.
- 투고규정 제1조 "저자 인적사항 미기입"은 학술지 심사용 규정이고, 경진대회 보완 논문은 저자 표기가 필요하므로 그대로 둔다.
